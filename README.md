# Bhavyarajsinh — Full-Stack Software Engineer Portfolio

> A clean, high-performance portfolio website built with modern Vanilla CSS, semantic HTML5, and reactive JavaScript. Designed with a minimalist Linear/Vercel-inspired tech aesthetic to showcase full-stack web applications, system design blueprints, and technical proficiencies.

![Portfolio Preview](./preview.png)

---

## ⚡ Key Highlights & Features

- **Linear / Vercel Aesthetic**: Sleek obsidian dark mode with subtle neon cyan accents and high-contrast light mode toggle.
- **Interactive Code Terminal**: Real-time typing animation profiling core tech stack (`React`, `Node.js`, `Express`, `PostgreSQL`, `MongoDB`, `Redis`).
- **Filterable Skills Matrix**: Categorized tech stack tabs (*Frontend & UI*, *Backend & APIs*, *Database & Cache*, *DevOps & Tools*) with proficiency meters.
- **Production-Grade Project Showcases**:
  - **CloudPulse**: Distributed API health & incident telemetry engine.
  - **OmniCommerce**: High-concurrency commerce engine with atomic database locking.
  - **DevConnect**: Real-time collaborative workspace with operational transform sync.
- **Architecture Spec Modals**: Interactive technical deep-dives covering concurrency, race-condition mitigation, and distributed caching.
- **ATS-Friendly Resume Preview**: Integrated modal with instant print/download capabilities.
- **Command Palette (`Ctrl + K` / `Cmd + K`)**: Quick keyboard-driven navigation across sections.
- **Contact & Interview Booking**: Form validation and 1-click clipboard email copy.

---

## 🛠️ Tech Stack

- **Core**: HTML5, Modern JavaScript (ES6+)
- **Styling**: Vanilla CSS3, CSS Custom Properties, Glassmorphism, CSS Grid & Flexbox
- **Design Tokens**: Space Grotesk, Inter, JetBrains Mono
- **Deployment**: Zero-dependency static web application, compatible with GitHub Pages, Vercel, Netlify, or any static host.

---

## 🚀 Running Locally

You can run this project locally with any static web server:

### Option 1: Python
```bash
python -m http.server 5174
```
Then visit `http://localhost:5174/`

### Option 2: Node.js / Vite
```bash
npm install
npm run dev
```
